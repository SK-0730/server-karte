# サーバーカルテ

> はじめてのサーバーに、はじめての健康診断

初学者が自宅サーバーをパソコンのアプリから診断し、外部公開の前後にありがちな設定ミスに気づいて直せるようにするデスクトップアプリ（就職作品・2026年度後期）。

## ドキュメント

設計資料は非公開です（リポジトリには含めていません）。

| ファイル | 内容 | WBS |
| --- | --- | --- |
| CLAUDE.md | AI（Claude Code）向けのルール | ― |
| docs/PROJECT.md | 企画概要（背景・機能一覧・設計方針・アピールポイント） | ― |
| docs/ARCHITECTURE.md | システム構成（アプリ内部・診断の流れ・使うコマンド） | 1.4 |
| docs/SCREENS.md | 画面設計・画面遷移・判定A〜E・伏せるルール | 1.5 |
| docs/DATA.md | データ設計（テーブル定義・ER図） | 1.6 |
| docs/DEVELOPMENT.md | 開発の流れ・CI/CD・起動方法・資料の置き場所 | ― |

予定・進捗は WBS（Excel）を正とする。
